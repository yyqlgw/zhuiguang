## 这是什么

**追光者 · 科技青年志** 是一个面向青年学生的科技人物学习与自我管理网页应用。

它不做资讯聚合，也不依赖网络。它把公开报道中的科技工作者事迹、名言与科技常识，整理成**可翻阅、可朗读、可答题、可打卡**的本地内容库，全部跑在一个 HTML 文件里。

三个设计取舍：

| 取舍 | 原因 |
|---|---|
| **人物可感** | 每位人物都有领域标签、事迹、关键时间线、资料来源和真实照片（部分），而不是停留在口号式宣传 |
| **闭环可坚持** | 阅读 → 答题 → 错题重练 → 打卡 → 学习报告，形成可延续的每日节奏，而不是一次性内容消费 |
| **离线可用** | 内容随页面打包，无账号、无后端、无网络请求；装到主屏后断网也能打开 |

## 部署到网上

站点是**纯静态**的，没有构建步骤，也不需要 Node / npm。把 `web/` 目录里的文件原样放到任意静态托管的**同一目录**即可：

| 文件 | 作用 | 大小 |
|---|---|---|
| `index.html` | 主页面：界面 + 内容 + 题库 + 海报数据 | ~2.0 MB |
| `photos.js` | 人物照片（先出页面，照片再补上） | ~310 KB |
| `sw.js` | 离线缓存（Service Worker） | ~1 KB |
| `manifest.webmanifest` | 应用信息：名称、图标、全屏、竖屏 | ~1 KB |
| `icon-192.png` / `icon-512.png` | 主屏幕图标 | ~160 KB |
| `splash-*.jpg` × 12 | iOS 启动图，按机型自动匹配，消除白屏 | ~510 KB |

合计约 **2.9 MB**。少一个文件不会白屏，但离线缓存或主屏图标会失效。

**步骤**（以 GitHub Pages 为例）：

1. 新建一个公开仓库（例如 `zhuiguang`）；
2. 把上面这些文件传到**仓库根目录**；
3. Settings → Pages → Source 选「Deploy from a branch」，分支 `main`、目录 `/ (root)`，保存；
4. 等 1 分钟，得到 `https://<用户名>.github.io/zhuiguang/` 这样的永久地址；
5. 手机浏览器打开 → 分享 → 「添加到主屏幕」。

国内访问慢可以换 Gitee Pages（需实名）或 Vercel / Netlify（拖拽上传）。

> **必须用 https**（或 `localhost`），Service Worker 才会注册；`file://` 直接双击打开能用，但没有离线缓存和主屏安装，只能当单页看。

**本地预览**：

```bash
python -m http.server 8899 --directory web
# 浏览器打开 http://localhost:8899
```

**更新**：`sw.js` 里的缓存版本号随内容变化，改了内容重新上传同名文件即可，老用户下次联网打开会自动取到新版，不用改文件名。若担心 CDN 缓存，强制刷新一次。

## 数据与备份

| 项目 | 说明 |
|---|---|
| 存储位置 | 浏览器 `localStorage`（主键 `zhuiguang_web_v1`），只在本机 |
| 上传 | **无**，没有任何后端请求 |
| 自动备份 | 每天首次打开写一份 `zhuiguang_snap_yyyymmdd`，保留最近 7 份，可在「我的」页一键恢复 |
| 手动备份 | 「我的 → 导出备份」导出 JSON（iOS 走系统分享面板存到「文件」），可再导入 |
| 清除 | 清除浏览器站点数据 / 无痕模式会丢数据；「我的 → 清空本地数据」需连续两次确认，不可撤销 |

> iOS Safari 有一条硬规则：**连续 7 天左右不打开这个网站，系统可能清掉该站点的存储**。
> 站点已申请 `navigator.storage.persist`，并在距上次打开超过 5 天时于「我的」页弹出提醒。
> 建议每周打开一次，每 1～2 周导出一份备份。

## 技术实现

| 类别 | 选型 |
|---|---|
| 形态 | 单个 `index.html`，原生 HTML + CSS + JavaScript，**无框架、无构建、无依赖** |
| 存储 | `localStorage`（含主数据 + 备份键 + 7 份每日快照） |
| 音频 | `WebAudio` 程序化合成白噪声，无音频文件 |
| 图像 | 人物照片 base64 内嵌于 `photos.js`；海报 base64 内嵌于 `index.html` |
| 导出 | `Canvas` 绘制分享卡与学习报告长图，`Blob` + 下载 / 系统分享面板 |
| 语音 | `SpeechSynthesisUtterance`（`zh-CN`） |
| 离线 | Service Worker：导航请求先走网络、失败回退缓存；其余资源缓存优先 |
| 适配 | `env(safe-area-inset-*)` 安全区、`viewport-fit=cover`、iOS 内嵌启动图、横屏遮罩、深色模式 CSS 变量 |

> 刻意不引入框架和第三方库，全文一个文件，是为了在答辩时能讲清每一处实现，而不是「用了什么黑盒」。

## 已知限制

| 限制 | 说明 |
|---|---|
| 每日提醒 | 网页只能在**页面开着的时候**弹通知；iOS 添加到主屏后不支持后台推送，建议配合系统闹钟 |
| iOS 存储清理 | 长期不打开可能被系统清数据，靠自动快照 + 手动导出兜底 |
| 横屏 | iOS 不允许网页锁方向，横屏时显示「请竖屏使用」遮罩，转回竖屏即可 |
| 震动 | iOS 不支持 `navigator.vibrate`，只有安卓 Chrome 有反馈 |
| 白噪声音色 | 实时合成比真实录音略「电子」，换来的是零音频体积 |
